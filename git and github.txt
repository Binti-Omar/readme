Slice From the Start



By leaving out the start index, the range will start at the first character:

Example

Slice To the End

Get the characters from position 2, and all the way to the end:

b = "Hello, World!"

print(b\[2:])

Negative Indexing

Example



Get the characters:



From: "o" in "World!" (position -5)



To, but not included: "d" in "World!" (position -2):

b = "Hello, World!"

print(b\[-5:-2])

The MIN() function returns the smallest value of the selected column.

FROM Products;

Example

FROM Products;



Here we use the MIN() function and the GROUP BY clause, to return the smallest price for each category in the Products table:

HOW TO ADD CSS TO A WEBPAGE

\-There are 3 ways of applying css to a webpage:-> choice depends on how much styling is needed

1.Inline css

\*\* quick and short css - applied on the element directly using style attribute

\*\* useful when not much css is needed or when testing designs



2.Internal css

\*\* written outside the elements but still inside the html document using style tags <style> </style>

\*\* written in the head section

\*\* useful for when you have moderate amount of css to apply but for one page



3.External css

\*\* css is written in an external file (.css) and linking it to a html document using link tag (placed in head section)

\*\* very practical when a lot of css is to be applied

\*\* this is the most efficient and recommended wy of writing css

CSS POSITIONING

\-Controls how elements aare placed on a page



Why Positioning Matters?

1.Precise Control -place elemnents exactly where you want

2.Layering - controls what sits on top -use z index

3.Complex UI patterns - modals, dropdowns ,sticky heaaders , tooltips



TYPES OF POSITIONING

1.static

\*\* default positioning

\*\* elements follow normal document flow (top to bottom ,left to right)

\*\* offsets dont apply in position:static\\

\*\*offsets are properties used to move elements - top, right , bottom , left



2.relative

\*elements still remain in normal document flow but can visually shifted relative to their

original / normal / expected position

\*\*allows for offsets

\*\*other elements around it dont move





3.absolute

\*\*positions an element relative to its ancestor's position which can have any position other than static

\*\* ignores normal document flow -ignores other elements



4.fixed

\*\*positions an element relative to the viewport

\*\*ensures an element always remains in your viewport

\*\*doesnt move when the page is scrolled



5.sticky

\*\*acts like relative until the scroll position reaches the threshold



6.inherit, unset







DISPLAY

Controls how an element is displayed on a page (layout)



1.block

\*\* element takes up the full width of its parent container

\*\* element always starts on a new line

\*\* you can set width , height , margins and padding



2.inline

\*\* doesnt start on a new line

\*\* only takes up as much width as the content

\*\* you cant set width or height (only allows margins and padding horizontally)





3.inline-block

\*\* similar to inline but allows for setting of width and height



4.none

\*\*completely removes an element from the layout

\-> the element isnt visible and doesnt take up space



5.flex

\*\*turns the element into a flex container

\*\* by default it arranges elements in row format



\*\*display:flex -> creates a flex container for you to decide how to place items



\*\*flex-direction - decides the axis and order in which elements are arranged

&#x20;               \*-> row(default)\*



&#x20;               \*-> row-reverse\*



&#x20;               \*-> column\*



&#x20;               \*-> column-reverse\*









\*\*justify-content - how items are aligned in an axis

&#x20;   \*-> space between - items spread out leaving no spaces at the edges\*



&#x20;   \*-> space around - equal space around each item\*



&#x20;   \*-> space evenly - equal space everywhere\*



&#x20;   \*-> center - center items\*



&#x20;   \*-> flex start - stick to the start\*



&#x20;   \*-> flex end - stick to the end\*

to write our own custom CSS

\-It comprises of pre-built components and associated utilities



UTILITIES

\-class helpers that act as a shorthand for writing custom css

GRID

\-System for organizing content on a webpage using rows and columns (just like a table but more flexible)

\-> helps align items neatly and responsively across different screen sizes



Purpose

1.Consistency - uniform layout, spacing and alignment

2.Responsiveness - webpage adapts automatically to different screen sizes



\*\*Container\*\* - wrappers for your grid

\-provide padding and centering of content

1\. .container - fixed width, responsive to breakpoints

2\. .container-fluid - full-width , spans the entire viewport



\*\*rows\*\* - flex containers that holds the columns

.row -> ensures columns are aligned



\*\*columns\*\* - hold the actual content and follow the 12-column layout system

.col -> auto equal width



m- margin all round

mx -> x axis

my -> y axis

me - margin end (right)

ms - margin start (left)





Bootstrap is mobile-first in terms of responsiveness

\-> start from the smallest screen and move upward

\-> define how columns behave to various screen sizes starting from the smallest



\*\*Breakpoints - defining points where your layout changes depending on screen width

\-> sm, md ,lg ,xl ,xxl



col-12 -> full stack width -> default behaviour for an xs screen size

col-sm -> alignment of columns on a small screen size
