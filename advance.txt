### 1.Rest API

\-Representational State Transfer Application Programming Interface

* REST → Representational State Transfer — a set of architectural principles/style for designing web services.REST is a way of designing an API where resources are accessed through URLs and manipulated using standard HTTP methods, with data commonly exchanged as JSON.
* API → Application Programming Interface — a way for different software applications to communicate



###### RULES OF REST API

\# 1. Data is transferred as key value-pairs called JSON.Sending from JS as JSON Object and from python as dictionary

\# 2. You must define routes/URL

\# 3. You must define a HTTP method(GET,POST,PUT,DELETE,PATCH)

\# 4. You must define a status code(200,201,404,401,500)

\# 200 → success,201 → created,400 → bad request,401 → unauthorized,404 — Not Found,409 → conflict (email exists),500 → server error

How the whole process works
1.server send consumer_key and consumer_secret to daraja api then daraja send back a token valid for an hour 
2.stk push request is sent from the server to daraja then daraja sends back the checkoutrequestid to the api
3.after the server receives the id it saves the payment as pending in the database
4.then a prompt is sent to the customer and they enter the pin 
5.then callback with the result is sent back to the server from daraja api
6.after the server receives the callback the database saves the payment as complete
