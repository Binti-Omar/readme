Steps of creating a .env
Step 1 — Create the .env file
Step 2 — Put your Flask secret key in .env and passwords
Step 3 — Install python-dotenv(pip install python-dotenv)
Step 4 —  connect .env file to your Python code.Add the imports(from dotenv import load_dotenv,import os,from flask import Flask)
Step 5 — Tell Python to load the .env file:Immediately after these two lines:load_dotenv()
Step 6 — Add .env to .gitignore


What you've learned here

You now know the difference between:

.env → stores sensitive configuration
os.getenv() → retrieves a value from .env
load_dotenv() → makes .env available to Python
.gitignore → prevents .env from being uploaded to GitHub
